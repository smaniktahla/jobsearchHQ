Admin

Add people and set up single sign-on. Only administrators see this page.

Do this first

  1. Under Users, enter a name, an email address and a temporary password, then click Add User. Tell the person their temporary password; they should change it after signing in.
  2. Optional: under Single Sign-On, connect your organization's sign-in service so people can use it instead of a password.

Common questions

Does everyone share the same jobs?

No. Each person has their own separate jobs, resumes and settings.

Do I have to set up single sign-on?

No, it is optional. Passwords work without it.
