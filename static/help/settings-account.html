Account

Your sign-in details, password and a backup of your settings.

Do this first

  1. Check Signed in as to confirm which account you are using.
  2. Change your password under Change Password (at least 10 characters).
  3. Use Export Config to save a backup of your settings to a file.

Common questions

What does Run setup again do?

It walks through the setup steps again, with your answers filled in. Nothing is erased.

Is the backup safe to share?

No. The backup includes your API keys and email password in plain text. Keep the file private and delete it when you are done.

What is Import Config?

It loads a backup file you saved earlier and replaces the matching settings.
